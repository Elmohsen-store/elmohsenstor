المحسن ستور - النسخة الكاملة

تم تنفيذ خطة الملف المرفق: منتجات من Supabase، صفحة منتج، سلة، شراء متعدد الخطوات، حساب حسب نوع المستخدم، لوحات المشتري والبائع والمدير، الطلبات وتتبعها، المفضلة، العناوين، المراجعات، رفع صور المنتجات وStorage، وإدارة البائعين والطلبات والمنتجات.

التركيب:
1- شغّل database.sql بالكامل في Supabase SQL Editor.
2- تأكد من config.js.
3- أنشئ حسابك ثم اجعله admin بالسطر الأخير في database.sql باستخدام User ID.
4- ارفع الملفات إلى الاستضافة.

ملاحظة: طرق الدفع الإلكترونية معروضة في خطوة الدفع، لكن ربط بوابة دفع فعلية يحتاج بيانات مزود دفع ومفاتيح API؛ لم يتم اختلاق تكامل غير موجود.


ملاحظات الإصلاح - 8 نوفمبر 2026:
- إصلاح خطأ JavaScript نحوي كان يمنع common.js من العمل بسبب وجود وسم style داخل الدالة.
- توحيد عميل Supabase المستخدم في صفحات المتجر وتسجيل الدخول.
- إصلاح اختيار نوع حساب المشتري وجعل الاسم مطلوباً عند التسجيل.
- منع حذف سلة الزائر إذا فشلت مزامنتها مع حسابه.
- إضافة فحص توفر المخزون عند الإضافة للسلة وتغيير الكمية.
- إيقاف تحويل العميل إلى واتساب إذا لم يتم حفظ الطلب وعناصره في قاعدة البيانات بنجاح.
- فصل صفحات إدارة الطلبات والمنتجات والبائعين والمستخدمين بدلاً من عرض لوحة المدير نفسها في كل صفحة.
- إضافة روابط صفحات الإدارة ورسائل أوضح عند فشل العمليات.
- إضافة حماية تمنع المستخدم من ترقية نوع حسابه بنفسه، وقصر تعديل حالة الطلب على المدير.
- جعل نوع product_id في جداول الطلبات والسلة والمفضلة والمراجعات يتبع نوع products.id (bigint أو uuid). إذا كان هناك جدول قديم يحتوي بيانات بنوع متعارض، سيظهر خطأ واضح بدلاً من تحويل بياناته عشوائياً.

مهم:
- شغّل database.sql المحدّث في Supabase SQL Editor بحساب مالك المشروع.
- تأكد أن UID الموجود في README_ADMIN_UID.txt هو حساب المدير الصحيح. قاعدة البيانات الآن تفعّله كمدير إذا كان صفه موجوداً في profiles عند تشغيل SQL.
- لا تضع Service Role Key في ملفات الموقع. المفتاح الموجود في config.js مفتاح نشر (Publishable) ويجب الاعتماد على RLS.
- لا أستطيع اختبار اتصال Supabase الفعلي أو تنفيذ SQL على مشروعك من هنا؛ بعد رفع النسخة وتشغيل SQL اختبر التسجيل والمنتجات والطلبات بحساب مشتري وبائع ومدير.


ملاحظات إصلاح النسخة الحالية:
- عرض اسم المتجر من View محدود بالأعمدة العامة فقط: seller_public_profiles.

- إتمام الطلب أصبح يستدعي الدالة place_store_order داخل PostgreSQL؛ السعر والشحن والمخزون تُراجع من قاعدة البيانات، ويُحفظ الطلب وعناصره ويُخصم المخزون في معاملة واحدة.
- يجب تشغيل ملف database.sql بالكامل مرة أخرى في Supabase SQL Editor قبل نشر ملفات الواجهة الجديدة.
- لا يمكن تأكيد التشغيل الفعلي أو صلاحيات مشروع Supabase دون تشغيل SQL على المشروع واختبار حساباته الحقيقية.
