المحسن ستور - النسخة الكاملة

تم تنفيذ خطة الملف المرفق: منتجات من Supabase، صفحة منتج، سلة، شراء متعدد الخطوات، حساب حسب نوع المستخدم، لوحات المشتري والبائع والمدير، الطلبات وتتبعها، المفضلة، العناوين، المراجعات، رفع صور المنتجات وStorage، وإدارة البائعين والطلبات والمنتجات.

التركيب:
1- شغّل database.sql بالكامل في Supabase SQL Editor.
2- تأكد من config.js.
3- أنشئ حسابك ثم اجعله admin بالسطر الأخير في database.sql باستخدام User ID.
4- ارفع الملفات إلى الاستضافة.

ملاحظة: طرق الدفع الإلكترونية معروضة في خطوة الدفع، لكن ربط بوابة دفع فعلية يحتاج بيانات مزود دفع ومفاتيح API؛ لم يتم اختلاق تكامل غير موجود.
